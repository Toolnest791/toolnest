EASIEST FREE PUBLISHING METHOD: CLOUDFLARE PAGES
------------------------------------------------
You will need a free Cloudflare account and a free GitHub account.

A. Create your GitHub account
1. Open https://github.com/
2. Sign up or sign in.
3. Create a new repository named: toolnest
4. Choose Public or Private (either works for a manual upload workflow).
5. Create the repository.

B. Upload the website files
1. Open the new toolnest repository.
2. Choose "Add file" > "Upload files".
3. Unzip the ToolNest ZIP on your device first.
4. Upload ALL files inside the toolnest folder (not the ZIP itself).
5. Scroll down and choose "Commit changes".

C. Publish with Cloudflare Pages
1. Open https://dash.cloudflare.com/
2. Create a free account or sign in.
3. In the dashboard choose Workers & Pages.
4. Choose Create application > Pages > Connect to Git.
5. Connect GitHub and select the toolnest repository.
6. For a plain HTML website, use these settings:
   - Framework preset: None
   - Build command: leave blank
   - Build output directory: /
7. Click Save and Deploy.
8. Cloudflare will provide a live address similar to https://your-project.pages.dev

D. Check your live website
1. Open the pages.dev address on your phone.
2. Test the search, filters, and each of the 12 tools.
3. If something is wrong, tell ChatGPT what happened and share the error text or screenshot.

E. Google indexing (after launch)
1. Open https://search.google.com/search-console/
2. Add your website property.
3. Verify ownership using the method Google provides.
4. Submit your sitemap when you have created one with your final domain.
5. Indexing and ranking can take time; neither is guaranteed.
